WebAssembly is a binary instruction format that runs in every modern browser. It was designed to give compiled code a fast path to the web, without the overhead of interpreting JavaScript. Where JS has to be parsed and JIT-compiled at runtime, WASM arrives already in machine-oriented form. The browser validates it once and then executes it with very little overhead.
