A Progressive Web Application that fetches real-time weather data while gracefully degrading to cached data when offline. Uses the OpenWeather API with automatic geolocation support.

## PWA Features

Service worker for network-first caching, installable manifest file, background sync for delayed data refresh, and an adaptive UI that adjusts colors based on current weather conditions.

## Technical Details

Built with vanilla HTML, CSS, and JavaScript to demonstrate core PWA APIs including the Cache API, Notification API, and Fetch event interception in service workers.
